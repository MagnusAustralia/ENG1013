## 📦 Getting Started

### Prerequisites

Ensure that you have previously flashed FirmataExpress to the Arduino Uno

Either use the global python environment (what you have likely done) or use a manager such as uv, to install pymata4

Windows:

```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

macOS:

```bash
brew install uv
```

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/MagnusAustralia/ENG1013.git
   cd ENG1013
   ```

2. **Install dependencies**

   ```bash
   uv sync
   ```

3. \*\*To run a file
   ```bash
   uv run main.py
   ```
